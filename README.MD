# Telegram Bot для связи с группой

Бот пересылает сообщения пользователей в указанную группу и позволяет администраторам отвечать на них через inline-кнопки.

## Переменные окружения

- `BOT_TOKEN` – токен бота (обязательно)
- `CHANNEL_ID` – ID группы (числовой, например `-1001234567890`) или @username (по умолчанию `-1005252934052`)
- `REDIS_URL` – опционально, строка подключения к Redis
- `PORT` – порт для health check (Railway устанавливает автоматически)

## Деплой на Railway

1. Создайте репозиторий и загрузите эти файлы.
2. Подключите репозиторий к Railway.
3. Добавьте переменные `BOT_TOKEN` и при необходимости `CHANNEL_ID`, `REDIS_URL`.
4. **Важно**: Добавьте бота в группу и назначьте администратором с правом «Читать сообщения».
5. Railway автоматически соберёт и запустит бота.

# Telegram Bot для связи с каналом

Бот пересылает сообщения пользователей в указанный канал и позволяет администратору отвечать на них через inline-кнопки.

## Переменные окружения

- `BOT_TOKEN` – токен бота (обязательно)
- `CHANNEL_ID` – ID канала (по умолчанию `@rethewf`)
- `DATABASE_URL` – (опционально) строка подключения к PostgreSQL
- `PORT` – порт для health check (Railway устанавливает автоматически)

## Деплой на Railway

1. Создайте репозиторий на GitHub и загрузите все файлы.
2. Подключите репозиторий к Railway.
3. В настройках проекта добавьте переменные окружения `BOT_TOKEN` и при необходимости `CHANNEL_ID`.
4. Railway автоматически соберёт и запустит контейнер.

> Убедитесь, что бот добавлен в администраторы канала!
